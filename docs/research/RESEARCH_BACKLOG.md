# Research Backlog

No research is performed by this document. The following known topics require future technical investigation:

| Topic | Expected outcome |
|---|---|
| OBS Studio 32.x plugin SDK and build strategy | Supported toolchain, ABI, versioning, and build constraints. |
| Official native plugin installation paths | Verified binary, data, and user-data placement. |
| Dock integration | Supported UI mechanisms, lifecycle, and compatibility. |
| OBS audio integration | Safe TTS routing, monitoring, device, and failure behavior. |
| OBS WebSocket capabilities | Supported operations, events, authentication, and responsibility boundaries. |
| C++ to .NET IPC strategy | Transport, protocol, authentication, versioning, timeouts, and recovery. |
| Process isolation | Failure containment and safe degradation between OBS and Assistant Core. |
| SQLite local lifecycle | Library, migrations, concurrency, corruption recovery, backup, retention, and permissions. |
| Windows Credential Manager / DPAPI | Threat model, scope, portability, upgrade, repair, and uninstall behavior. |
| YouTube Live Chat integration | Official APIs, OAuth, scopes, quotas, polling/stream behavior, and revocation. |
| AI provider abstraction | Minimum provider contract, streaming, cancellation, errors, limits, and BYOK behavior. |
| Local AI provider viability | Hardware, latency, packaging, isolation, and operational constraints. |
| TTS provider abstraction | Voice capabilities, streaming, formats, cancellation, limits, and safe output. |
| Installer technology | Suitable Windows packaging, signing, elevation, and OBS integration constraints. |
| Upgrade, repair, and uninstall | Data retention, credentials, rollback, compatibility, and cleanup behavior. |
| OBS version compatibility strategy | Supported version range, detection, regression matrix, and deprecation policy. |
