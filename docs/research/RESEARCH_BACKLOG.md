# Backlog de Research

Este documento não executa pesquisa. Os tópicos conhecidos abaixo exigem investigação técnica futura:

| Tópico | Resultado esperado |
|---|---|
| SDK de plugins do OBS Studio 32.x e estratégia de build | Toolchain suportada, ABI, versionamento e restrições de build. |
| Caminhos oficiais de instalação de plugin nativo | Locais validados para binários, dados do plugin e dados do usuário. |
| Integração de Dock | Mecanismos de UI suportados, ciclo de vida e compatibilidade. |
| Integração de áudio do OBS | Roteamento seguro de TTS, monitoramento, dispositivos e comportamento de falha. |
| Capacidades do OBS WebSocket | Operações, eventos, autenticação e limites de responsabilidade suportados. |
| Estratégia de IPC entre C++ e .NET | Transporte, protocolo, autenticação, versionamento, timeouts e recuperação. |
| Isolamento de processo | Contenção de falhas e degradação segura entre OBS e Assistant Core. |
| Ciclo de vida local do SQLite | Biblioteca, migrations, concorrência, recuperação de corrupção, backup, retenção e permissões. |
| Windows Credential Manager / DPAPI | Threat model, escopo, portabilidade, upgrade, repair e uninstall. |
| Integração com YouTube Live Chat | APIs oficiais, OAuth, scopes, quotas, comportamento de polling/stream e revogação. |
| Abstração de providers de IA | Contrato mínimo, streaming, cancelamento, erros, limites e comportamento de BYOK. |
| Viabilidade de IA local | Hardware, latência, empacotamento, isolamento e restrições operacionais. |
| Abstração de providers de TTS | Vozes, streaming, formatos, cancelamento, limites e saída segura. |
| Tecnologia de instalação | Empacotamento Windows adequado, assinatura, elevação e restrições de integração com OBS. |
| Upgrade, repair e uninstall | Retenção de dados, credenciais, rollback, compatibilidade e limpeza. |
| Compatibilidade entre versões do OBS | Faixa suportada, detecção, matriz de regressão e política de descontinuação. |
