# Architecture Documentation

Architecture is **NOT STARTED** as an approval phase. This directory currently contains only a documentation-and-planning baseline.

- [Project Structure](PROJECT_STRUCTURE.md) describes the repository as it exists and labels possible product directories as planned.
- `decisions/` is reserved for approved Architecture Decision Records.
- `diagrams/` is reserved for architecture diagrams produced during an authorized architecture phase.

No file in this directory approves the OBS integration split, IPC protocol, Dock mechanism, audio routing, credential storage, database implementation, provider libraries, or installer technology.
