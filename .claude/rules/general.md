# General Conventions

- Use English for source code, technical identifiers, Agents, Skills, and tool-required structures when appropriate.
- Communicate with the client in Brazilian Portuguese.
- Use Semantic Versioning (`MAJOR.MINOR.PATCH`) for product components unless an approved ADR states otherwise.
- Operational branch names are `main`, `develop`, `hml`, `feature/task-*`, and `release/1.0.0XXXX`; Git setup is complete.
- Human-facing project documentation and pull request descriptions use Brazilian Portuguese (`pt-BR`). Preserve technical identifiers, commands, official technology names, Conventional Commits, and tool-required structure in English when appropriate.
- Use Conventional Commits after Git setup is available and an approved task permits a commit.
- Do not create product source, solution, database, plugin, Dock, integration, installer, Docker, or cloud artifacts before their approved task.
- Never modify `%APPDATA%\obs-studio` during planning or engineering bootstrap.
- Do not import files from OBS Truck Live Optimizer or other projects.
